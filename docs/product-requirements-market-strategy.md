# AI Career Agent — متطلبات المنتج واستراتيجية السوق

الحالة: معتمد للتأسيس في 2026-08-06. هذه الوثيقة هي مرجع قرارات المنتج، وليست
ادعاءً بأن جميع قدرات الـMVP أصبحت جاهزة للإنتاج. حالة التنفيذ وخطة 12–16 أسبوعًا
موثقتان في [قصص المستخدم والتدفقات وخارطة الطريق](user-stories-workflows-roadmap.md).

## 1. الخلاصة التنفيذية

نبني وكيلًا مهنيًا ثنائي اللغة للسعوديين في بداية مسيرتهم المهنية، يبدأ بوظائف
البرمجيات والبيانات والمنتج والتصميم الرقمي. يساعد المستخدم على اختيار الفرص
الصحيحة، وتجهيز طلب مخصص، ومتابعة النتيجة، وفق قاعدة غير قابلة للتجاوز:

> لا تُكتب حقيقة مهنية ما لم تكن مستندة إلى معلومة راجعها المستخدم ويمكن تتبعها.

قرارات الإطلاق:

- السعودية أولًا، وتجربة محسنة للسعوديين ذوي خبرة 0–5 سنوات؛ يُسمح للمقيمين دون
  وعد بتجربة محلية مكتملة.
- B2C ذاتي أولًا، ثم شراكات جامعات ومعسكرات.
- فريق صغير ومدة 12–16 أسبوعًا للـMVP.
- التقديم النهائي يدوي على منصة صاحب الوظيفة.
- «فرصة المقابلة» نطاق جاهزية مفسّر، وليست نسبة احتمالية.
- المقياس الشمالي هو المقابلات البشرية المؤهلة لكل طلب أكّد المستخدم إرساله.

لا نستخدم ادعاء «أول وكيل مهني بالذكاء الاصطناعي». التموضع:

> **قدّم بذكاء، لا بكثرة: وكيل مهني للسوق السعودي، يبني كل توصية وكل جملة من
> حقائق مهنية يمكنك مراجعتها وإثباتها.**

## 2. المشكلة والمستخدم

المستخدم الأساسي باحث عمل سعودي مبكر المسيرة، يستهدف دورًا رقميًا أو تقنيًا داخل
السعودية، ويتعامل بالعربية والإنجليزية. ملفه موزع بين CV ولينكدإن والشهادات
والمشاريع، ولا يعرف أي الفرص تستحق وقته، وقد تعرّضه أدوات التوليد لادعاءات غير
صحيحة، ولا يربط عادة بين الوظيفة ونسخة الطلب والنتيجة.

الوظائف التي يستأجر المنتج لأجلها:

- جمع كل ما أنجزه مهنيًا في ذاكرة موثوقة.
- اختيار الوظائف التي تستحق الوقت مع تفسير القرار.
- تخصيص الطلب من دون اختلاق معلومة أو رقم.
- كشف النقص الحقيقي قبل التقديم.
- ربط كل طلب بنسخته وقناته ونتيجته لتحسين القرارات التالية.
- التحول لاحقًا إلى ذاكرة ومرشد مهني بعد الحصول على الوظيفة.

## 3. نطاق الـMVP ومعايير القبول

| المجال | السلوك المطلوب |
|---|---|
| الملف المهني | تعليم، خبرات، شهادات، مهارات، مشاريع، لغات، إنجازات، أهلية وتفضيلات؛ إدخال يدوي أو PDF/DOCX. |
| LinkedIn | رفع PDF أو أرشيف بيانات نزّله المستخدم بنفسه فقط؛ لا ربط حساب ولا scraping، وتُهمل بيانات الآخرين. |
| سجل الأدلة | لكل حقيقة مصدر وحالة `extracted/confirmed/unconfirmed`؛ وكل ادعاء مولّد يتتبع حقيقة مؤكدة. |
| الوظائف | إدخال وصف أو رابط يدويًا، ثم feed/API مرخص عند توافر عقد؛ لا وعد بتغطية مصدر غير مرخص. |
| التحليل | متطلبات إلزامية ومفضلة، خبرة، مهارة، شهادة، تعليم، لغة، موقع وأهلية؛ كل بند مغطى أو مفقود أو غير معلوم. |
| التغطية | نسبة تغطية متطلبات بأوزان ظاهرة، لا احتمال قبول أو مقابلة. |
| القرار | «تقدّم الآن»، «حسّن ثم تقدّم»، «عائد منخفض»، أو «نحتاج معلومات»، مع إمكانية تصحيح المتطلبات وإعادة التحليل. |
| الجاهزية | منخفضة/متوسطة/مرتفعة مع ثقة وأسباب، دون احتمال رقمي في الـMVP. |
| المستندات | CV ورسالة بالعربية أو الإنجليزية، ATS-safe، مع فرق عن الأساس ومصدر كل ادعاء وحظر غير المدعوم. |
| التسليم | حزمة قابلة للتنزيل أو النسخ بعد مراجعة المستخدم، ثم فتح الصفحة الأصلية؛ المستخدم يضغط Submit. |
| التتبع | مكتشفة، محفوظة، قيد التجهيز، جاهزة، تم التقديم، مقابلة، مرفوضة، عرض، منسحب. |
| النتائج | تأكيد يدوي للنتيجة؛ تحليلات شخصية أولًا ولا نموذج تنبؤي قبل بلوغ جودة وحجم بيانات مناسبين. |
| اللوحة | أفضل الفرص، الإجراءات المطلوبة، المتابعات، جودة الملف وقمع النتائج دون دفع للإغراق. |

خارج النطاق:

- mass/auto-apply، إضافات المتصفح، ملء نماذج المنصات أو تخزين كلمات مرور/cookies.
- scraping أو مزامنة LinkedIn وIndeed وBayt وGulfTalent.
- ضمان وظيفة أو نسبة مقابلة رقمية.
- بوابة أصحاب عمل/جامعات أو مساعد سري أثناء مقابلة حقيقية.
- التوسع الخليجي وكل العائلات الوظيفية في الإصدار الأول.

## 4. مبادئ الجودة والثقة

1. **الحقيقة قبل البلاغة:** الهدف الصفري عدم وجود ادعاء مهني غير مدعوم في مخرج قابل للاستخدام.
2. **الإنسان صاحب القرار:** مراجعة المستخدم مطلوبة قبل اعتماد مستخرج أو جعل مستند قابلًا للتصدير.
3. **فصل الحقيقة عن الصياغة:** تتحسن الصياغة فقط إن بقي المعنى والعلاقة والكمية والفاعل مدعومة.
4. **عدم استنتاج الأهلية:** الجنسية وحق العمل والتفضيلات يصرح بها المستخدم.
5. **الشفافية:** كل درجة تعرض تعريفها ومكوناتها والناقص وغير المعلوم.
6. **تقليل البيانات:** لا تدريب افتراضي على بيانات المستخدم، مع تصدير وحذف قابل للتدقيق.
7. **ثنائية لغة أصلية:** RTL/LTR ومخرجات عربية وإنجليزية متكافئة المعنى.
8. **الإتاحة:** استهداف WCAG 2.2 AA وتجربة هاتف كاملة.

لا تدخل بيانات حقيقية إلى استضافة الإنتاج قبل تقييم نظام حماية البيانات الشخصية
ونقل البيانات والموردين الفرعيين وموقع المعالجة.

## 5. السوق ونموذج العمل

لا يوجد رقم رسمي دقيق لفئة أدوات الباحث عن عمل بالذكاء الاصطناعي؛ لذلك لا نخلط
B2C مع ATS ومنصات التوظيف في TAM واحد. المرساة التخطيطية منخفضة الثقة هي نحو
217 ألف سعودي عاطل يحمل دبلومًا أو أعلى، استنادًا إلى دمج تقديرات السكان مع
مؤشرات سوق العمل للربع الأول 2026. المرساة تستبعد موظفين راغبين في الانتقال،
وتشمل تخصصات وخبرات خارج الشريحة؛ ليست SAM معتمدًا.

سيناريو اختبار لثلاث سنوات، لا توقع مالي:

- 2.2–17.3 ألف عميل مدفوع سنويًا عند الوصول إلى 1–8% من المرساة.
- 0.2–3.1 مليون ريال إيراد سنوي عند إنفاق 90–180 ريالًا لدورة بحث.
- يلزم feed مرخص أو بيانات جدارات/HRDF عن الباحثين الرقميين الفريدين قبل اعتماد
  TAM/SAM/SOM رسمي.

التسعير المقترح للاختبار:

- طبقة مجانية مفيدة: ملف موثق، Tracker، وعدد محدود من التحليلات.
- `Career Sprint` لمدة 90 يومًا هو العرض المدفوع الأساسي.
- اختبار 39 و69 و99 ريالًا قبل تثبيت السعر.
- لاحقًا اشتراك استمرارية مهنية، ثم B2B2C للجامعات والمعسكرات.

قبل تثبيت السعر: 20–30 مقابلة نوعية، concierge مع 50 مستخدمًا، ثم مسح كمي
واختبار دفع.

## 6. المنافسة والميزة المركبة

| المنافس | قوته | دلالته علينا |
|---|---|---|
| BaytGPT | عربي/إنجليزي، وظائف حية، تخصيص CV وJob Fit | لا تكفي عبارة «وكيل عربي شامل»؛ نحتاج ثقة وعمقًا سعوديًا أفضل. |
| Indeed Career Scout | بحث ومطابقة وCV وTracker مدعومة ببيانات Indeed | لا ننافس بحجم البيانات، بل بالاستقلال والتفسير والأدلة. |
| LinkedIn Premium | هوية وشبكة وJob Match | نبني سجلًا متعدد المصادر وقرارًا مستقلًا، لا نسخة LinkedIn. |
| Jobscan / Teal / Simplify | ATS والتخصيص والتتبع | قدرات أساسية وليست moat منفردة. |
| أدوات auto-apply | السرعة والحجم | نتموضع على جودة الطلب والالتزام والنتيجة. |

الميزة الدفاعية هي اجتماع:

1. **Career Evidence Graph** لربط الحقيقة والادعاء والمصدر والتحقق.
2. **Explainable Apply Decision** لفصل الإلزامي والمفضل والمفقود وغير المعلوم.
3. **Saudi Digital Career Ontology** للمسميات والمهارات والشهادات والسياق المحلي.
4. **Outcome Graph** لربط الفرصة والنسخة والقناة والنتيجة.
5. **Policy-Aware Orchestrator** بصلاحيات منفصلة وافتراضي `false` لكل أتمتة.
6. **استمرارية مهنية** تحول المنتج لاحقًا من أداة موسمية إلى ذاكرة مهنية.

## 7. القياس

المقياس الشمالي:

`دعوات مقابلة بشرية مؤهلة مرتبطة بوظيفة ÷ الطلبات التي أكد المستخدم إرسالها`

تُستبعد رسائل البريد الآلية واختبارات الفرز والتواصل غير المرتبط بالوظيفة.

المؤشرات المبكرة:

- إكمال ملف موثق، أول تحليل، وأول CV مخصص.
- الزمن من إضافة الوظيفة إلى حزمة جاهزة.
- نسبة الحقائق المؤكدة وتغطية الأدلة.
- توافق المستخدم مع قرار التقديم.
- تحويل المجاني والمدفوع والاحتفاظ خلال 90 يومًا.
- تسجيل النتائج بعد التقديم.

مؤشرات الحماية:

- صفر ادعاءات غير مدعومة في المخرجات القابلة للاستخدام.
- صفر جلب أو تقديم مخالف لسياسة مصدر.
- لا يُستخدم عدد الطلبات كمؤشر نجاح.
- قياس فروق الجودة حسب اللغة والجنس ونوع الخلفية المهنية.

## 8. سياسات المنصات

كل مصدر له سجل صلاحيات: طريقة الإدخال، الإذن/الترخيص، تاريخ مراجعة الشروط،
وإمكانات البحث والجلب والتقديم الآلي. الافتراضي دائمًا `false`.

- [LinkedIn User Agreement](https://www.linkedin.com/legal/user-agreement)
- [Indeed Terms](https://www.indeed.com/legal?hl=en)
- [Bayt Terms](https://www.bayt.com/en/pages/terms/)
- [GulfTalent Terms](https://www.gulftalent.com/terms)

في الـMVP لا يطلب الخادم صفحات هذه المنصات. الرابط metadata فقط، ولا تفعل أتمتة
مستقبلية إلا عبر API/شراكة تغطي الاستخدام صراحةً وبعد مراجعة قانونية.

## 9. اختبارات قبول حاكمة

- إنجاز بلا رقم: تتحسن صياغته، ولا يُخترع أثر كمي.
- شهادة أو تاريخ بثقة منخفضة: يبقى غير مؤكد ولا يدخل تحليلًا أو مستندًا.
- شهادة إلزامية غير موجودة بعد إعلان اكتمال فئة الشهادات: تظهر فجوة مستقلة.
- وصف غامض: «نحتاج معلومات»، لا قرار حاسم.
- رابط منصة: يحفظ فقط ولا يُجلب.
- العربية والإنجليزية تستندان إلى الحقائق نفسها دون اختلاف معنوي.
- كل جملة واقعية في مخرج نهائي تتبع حقيقة مؤكدة ومصدرًا معروفًا.
- لا نسبة مقابلة، ولا Submit، ولا mass apply، ولا حساب منصة خارجية.
- تعديل/سحب حقيقة يبطل التحليلات والمستندات المعتمدة عليها حتى إعادة المراجعة.
- حذف البيانات يمر بمسار قابل للتدقيق، مع توضيح ما لا يشمله مثل حساب الهوية الخارجي.

## 10. بوابات المرحلة التالية

- feed سعودي مرخص أو إبقاء الإدخال اليدوي وحده.
- تقييم PDPL ونقل البيانات وموردي الاستضافة والذكاء الاصطناعي.
- threat model، malware scanning، rate limits، سجل `AuditEvent` ومراقبة تشغيلية.
- اختبارات جودة عربية/إنجليزية، تحيز، وcorpus لوظائف رقمية سعودية.
- لا تثبيت للسعر قبل البحث النوعي وconcierge واختبار الدفع.
